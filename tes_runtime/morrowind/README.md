# MorrowindRuntime

Runs Morrowind's dialogue natively in Skyrim by porting OpenMW's dialogue engine
and MWScript VM into an SKSE plugin, instead of reshaping TES3 dialogue into TES5
records: topics, the dialogue filter, result scripts, object scripts, persuasion,
travel, alchemy apparatus, crime state, and its own dialogue menu
(`interface/morrowind_dialogue.swf`, generated by
`tools/generators/gen_morrowind_menu_swf.py`).

- Everything: [morrowind_runtime.md](../../docs/commentary/morrowind_runtime.md)
- Licensing: it links vendored **GPL-3.0** OpenMW (`external/openmw/`), which is
  why it is its own DLL. It also compiles the MIT `../common/` sources, which
  MIT allows. [morrowind_runtime.md](../../docs/commentary/morrowind_runtime.md#licensing)

Reads `Data\SKSE\Plugins\MorrowindRuntime\<plugin>\` (staged by
`tes5_import/dialogue/morrowind_sidecar.py`). Co-save owner `'MWRT'`. Log:
`MorrowindRuntime.log`; set `TESRUNTIME_VERBOSE` for per-tick script lines.

Source is in `plugin/`, namespace `tesruntime::mw`; headless test data is in
`testdata/`.

## Building

- `build.bat` → `..\dist\MorrowindRuntime.dll` (C++20, compiles the vendored
  OpenMW subset first).
- `build.bat openmw` compiles only the vendored OpenMW subset.
- `build.bat test` builds the headless tests: `store_test`, `filter_test`,
  `script_test`, `alchemy_test` (each prints `OK` / `all passed`) and
  `session_test` (a manual tool: `<sidecar root> <actor id>`). Run them from
  this folder: they read `testdata\` by relative path.
